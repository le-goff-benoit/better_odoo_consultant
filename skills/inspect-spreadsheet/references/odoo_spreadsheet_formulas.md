# Formules Odoo Spreadsheet clés

- `ODOO.PIVOT(...)` : récupérer une mesure depuis une source pivot Odoo.
- `ODOO.LIST(...)` : lire une valeur depuis une liste Odoo synchronisée.
- `ODOO.FILTER.VALUE(...)` : lire la valeur d'un filtre global.
- `ODOO.LOOKUP(...)` : disponible selon version/modules, utile pour retrouver une valeur liée.

La liste exhaustive est extraite au runtime depuis les sources JS locales quand elles sont disponibles.
